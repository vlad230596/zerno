## Правила ведения

- Документ фичи начинается со строки `Статус:` — она и есть источник правды о
  готовности.
- Раздел «Что осталось» / «Ещё нет» / «Порядок работ» в конце каждого файла
  фичи — его содержимое сводится в [backlog.md](./backlog.md).
- Ссылки на код — относительные, на конкретный файл. Они проверяемы, и это
  единственный способ заметить, что документ разошёлся с кодом.
